# I Fucking Hate Windows

I used to daily drive Fedora Linux til the start of the week. Unfortunately, for work reasons, I had to re-install Windows on my main PC, and there was no dual-boot that would save me. I am no stranger to distro hopping and trying new stuff every once in a while but god-damn, switching back to Windows has been such an unpleseant experience.

I spent around 2 hours just waiting for it to install and then to be asked a bazilian question that all the answers where **no** (telemetry questions) 😠😡. Then I had to uninstall all the pre-installed stuff like **LinkedIn** (why???) and **Microsoft Office**.

## The Journey Only Ends When I Kill Telemetry

After installing Windows and debloating the system a bit, there I went to the good old ``regedit`` to disable a ton of stuff, from Cortana to the awful search system they made. After that the system was usable, and I could start to install my programs and customizing Windows a little.

## Always Come Prepared

I already knew installing all my software and files would take a good hour or two, so beforehand in a Virtual Machine, I made a custom install script to download all my stuff. And thank god I did it, installing software and Windows mods like Wintoys was such a breeze.

### WSL my beloved

The only thing that is making my experience not suck is Windows subsystem for linux, thank you for giving me a way to use a linux system inside Windows for my projects 🙏.
