# The AC Saga

When I first moved into my apparment, it only had heating. It wasn't a problem at the time, but with the summer approaching, I finally got my first air conditioner! Thankfully, I didn't have to spend any money to get it, it was given to me by a neighbor who was moving out! 

But one issue was that it didn't have the window and hose attachments to make it work. This was easy to fix, I just went and bought them! The real problem appeared when I learned the connector from the hose to the AC was non-existent...

At first, I thought about doing some redneck engineering by just wrapping it with duct tape, and it worked for about 3 hours before the glue got hot enough to melt. With this problem in mind and with the heat growing, I spent some time finding a 3D model to connect it, since I was sure someone had done it before. Thankfully, I found something close enough with the proper dimensions and went to print it.

*Then my nozzle clogged mid-print 😭...*

It was not a simple clog, so I had to order a new nozzle. Fortunately, the lab where I started working has a bunch of 3D printers, so I was able to print it there!

After all of this trouble, I finally had the 3D print. When it came time for the test fit, the hose fitted like a glove. But when I went to connect it to the AC, another surprise: the tolerances were so **spot on** that it was actually slightly loose...

## **GOD DAMMIT**

To finish this saga, I just used some more redneck engineering by putting a bit of tape around the mouth of the connector so it would fit a bit more snugly, and so far it has been working well.

So yeah, fun times 🫠
